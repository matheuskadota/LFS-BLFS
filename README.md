# LFS-BLFS

Personal study and documentation repository for **Linux From Scratch (LFS)** and **Beyond Linux From Scratch (BLFS)**.

## Purpose

The goal of this project is to understand, through practical construction, how a GNU/Linux system is assembled from source.

The study focuses on topics such as:

- GNU/Linux toolchains
- Binutils and GCC
- Linux API headers
- Glibc
- linking and shared libraries
- filesystem hierarchy
- users and permissions
- device management
- `/dev`, `/proc`, and `/sys`
- system initialization
- systemd
- Linux kernel configuration and compilation
- boot process
- bootloaders
- software compilation and dependencies
- construction of a usable Linux system from source

The objective is not simply to finish an LFS installation, but to understand why each major component exists and how the pieces interact.

## Project Scope

The repository follows two main stages:

1. **Linux From Scratch**
   - Build a minimal GNU/Linux system from source.
   - Study the toolchain, userspace, kernel, filesystem layout, initialization, and boot process.

2. **Beyond Linux From Scratch**
   - Extend the base LFS system.
   - Study additional libraries, networking, security, graphical environments, development tools, and other userspace components.
